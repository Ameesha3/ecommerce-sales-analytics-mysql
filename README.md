# E-Commerce Sales Analytics — MySQL

## 📌 Project Overview

This project analyzes e-commerce sales data using MySQL to identify
revenue trends, customer behavior, product performance, regional
performance, discount impact, delivery efficiency, and customer
satisfaction.

The project demonstrates SQL-based business analysis using
aggregations, CASE statements, CTEs, subqueries, and window functions.

---

## 🎯 Business Objectives

- Analyze overall revenue and sales performance
- Identify top-performing product categories
- Compare regional performance
- Analyze customer purchasing behavior
- Evaluate the relationship between discounts and revenue
- Analyze delivery performance
- Identify high-value customers
- Measure customer satisfaction
- Generate actionable business insights
